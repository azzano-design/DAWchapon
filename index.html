How to install

  1. Go to the DAWchapon GitHub page and download the latest release from the Releases tab.
  2. Unzip the download, then move DAWchapon.component into ~/Library/Audio/Plug-Ins/Components/.
  3. If macOS blocks it as coming from an unidentified developer, open Terminal and run: 
    xattr -cr ~/Library/Audio/Plug-Ins/Components/DAWchapon.component
  4. Quit and reopen GarageBand so it rescans for new Audio Units.
  5. On any track, open the Plug-ins list in Smart Controls and add an Audio Unit under manufacturer Azzano Design → DAWchapon.
  6. Click the plugin's power button to switch it on, then crank the gachapon machine — whichever toy pops out decides your effect, until you spin again.
